# 專案模組化區塊規劃

- **一般專案管理**
  - 專案登錄、切換、目錄與檔案索引。

- **圖片專案與系列管理**
  - 圖片專案、系列切換、命名與版本關係。

- **對話與任務執行**
  - 對話歷史、任務狀態、取消與執行追蹤。

- **AI 請求與上下文**
  - 模型設定、材料組裝、歷史篩選與逾時處理。

- **圖片討論與創作**
  - 圖片理解、候選提示詞、產圖與修改流程。

- **摘要與記憶管理**
  - 對話、專案及系列摘要的產生與套用。

- **附件與檔案保存**
  - 附件、圖片、JSON 與任務索引的保存。
  - 三種保存模式：[storage_models.md](storage_models.md)

- **資料刪除與完整性**
  - 對話及系列刪除、孤立檔盤點與中斷復原。
  - 一般對話：[conversation_deletion_cleanup.md](conversation_deletion_cleanup.md)
  - 圖片系列：[image_project_deletion_cleanup.md](image_project_deletion_cleanup.md)

- **授權與存取控制**
  - 磁碟授權、AI 外送同意與管理碼驗證。

- **前端介面與互動**
  - 工作區、選單、對話框與操作狀態呈現。
