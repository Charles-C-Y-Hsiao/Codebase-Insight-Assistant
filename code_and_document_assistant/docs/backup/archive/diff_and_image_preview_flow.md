# 程式差異比較與圖片預覽操作流程

本文件分成兩個主題：程式差異比較，以及圖片預覽。每個主題都先說明目前介面層的位置，再說明操作、套件載入方式與驗證方式。

## 程式差異比較

### 介面層位置

差異比較位於任務卡片的修改工作台：

- `#task-workbench-*`：該任務的修改工作台章節。
- `.task-diff`：修改前後內容、套用、還原與驗證結果的容器。
- `#diff-details-*`：修改前後程式內容的展開／收合比較區。
- `#verification-details-*`：備份與完整驗證紀錄的展開／收合區。

使用者先在任務卡片展開「詳細資訊」，再展開「修改工作台」與差異比較內容；比較結果只提供檢視與複製，不會直接寫入檔案。

### 操作方式

- 展開「修改前後內容」後，預設顯示逐行差異：紅色為刪除、綠色為新增，並提供新舊行號與行內差異。
- `#task-workbench-*` 直接位於該任務卡片中；已不再依賴單一全域工作台或右側重複資料。
- 重啟服務後的歷史任務若未保存 before／after，會提示無法重建原文差異，並顯示可取得的驗證紀錄；不以目前檔案冒充當時的修改內容。
- 標題列顯示新增／刪除行數；程式依檔名副檔名上色。
- 使用「差異比較方式」選單切換「逐行差異／左右並排」；並排時水平捲動同步。
- 長段未修改內容預設收合，保留變更附近的上下文；可點行數列展開，也可「展開全部未修改內容」。並排模式兩側同步展開收合。
- 「複製修改前／複製修改後」複製完整原文，包含未顯示的行與原始縮排，不包含差異符號或行號。
- 比較不會寫入檔案；仍需使用原本的主機確認套用操作。
- 套件無法載入或內容過大時，保留完整原文比較與複製入口。沒有差異時顯示「內容相同」。

### 套件與載入方式

- diff2html UI Slim `3.4.52`：固定版本 jsDelivr CDN，用於差異呈現與語法上色。
- jsdiff `5.2.0`：固定版本 CDN，於瀏覽器將 before／after 轉成 unified diff。
- highlight.js `11.9.0` 的 GitHub 樣式：固定版本 CDN；語法上色程式包含在 diff2html UI Slim 中。
- 差異腳本只在第一次展開比較時載入；專案內容在瀏覽器內計算，不送至 CDN 進行比較。
- 服務的 CSP 僅增加上述固定 CDN 資源路徑。更新後需重新啟動服務並重新整理網頁。

### 驗證

- `node code_and_document_assistant/tests/review-viewers-browser.js` 會驗證差異上色、行數收合、模式切換、完整複製與 CDN 失敗備援。
- 測試確認比較只產生前端檢視結果，不會在檢視階段寫入檔案。
- 套用仍須經過主機確認，之後才進入備份與靜態驗證流程。

## 圖片預覽

### 介面層位置

圖片預覽有三個介面入口：

- `#image-draft`：輸入框中的草稿圖片縮圖。
- `#task-images-*`：任務卡片中的附件圖片縮圖。
- 圖片創作任務的圖片縮圖：由任務附件與同一 `imageCreation.seriesId` 的完成版本組成預覽集合。

點擊縮圖後開啟遮罩式 PhotoSwipe；預覽結束後回到原本的縮圖位置。

### 操作方式

點擊附件或生成圖片  
↓  
開啟遮罩式 PhotoSwipe 預覽  
↓  
使用底部 −／＋ 調整縮放，查看百分比；放大後可拖曳圖片  
↓  
左右箭頭或鍵盤 ←／→ 切換；右上角關閉或 Esc 返回對話

- 一般任務只切換該任務附件；不同任務的附件不混入。
- 圖片創作只切換同一 `imageCreation.seriesId` 的已完成版本，不混入其他圖片創作。
- 輸入框中的草稿縮圖也可點擊預覽，只切換目前草稿圖片。
- 支援圖片取得焦點後用 Enter／空白鍵開啟；關閉後回到原縮圖。
- 舊附件若因服務重啟而失效，沿用原本無法載入提示；不重建不存在的圖片。

### 套件與載入方式

- PhotoSwipe `5.4.4`：程式、CSS 與 MIT 授權保存在 `public/vendor/photoswipe-5.4.4/`，圖片預覽不向 CDN 載入套件。
- `public/image-viewer.js` 負責建立預覽資料、鍵盤操作、縮放控制、圖片說明與錯誤提示。
- `public/attachments.js` 負責草稿圖片載入、貼上、限制、刪除與縮圖建立。
- `public/index.html` 依序載入 PhotoSwipe、`image-viewer.js` 與附件相關腳本；更新後需重新啟動服務並重新整理網頁。

### 驗證

- `node code_and_document_assistant/tests/review-viewers-browser.js` 會驗證圖片縮放、鍵盤操作、關閉行為與圖片版本範圍。
- 測試使用隔離服務及合成圖片，不套用使用者的專案修改，也不呼叫圖片生成 API。
- 測試若找到 `runtime/viewer-test-assets/` 的固定版本套件，會攔截 CDN 請求並使用同版本內容；正式網頁使用本機保存的 PhotoSwipe 套件。
