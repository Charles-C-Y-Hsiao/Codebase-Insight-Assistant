### 4.2 一般程式檔案人工修改

1. 以主機路徑提出授權，勾選修改與所需靜態驗證權限，再以管理碼確認。
2. 選取一份程式檔，展開「實際程式檔案修改與驗證」，按「載入選取檔案」。
3. 編輯候選文字，用主機管理碼產生提案；右側查看修改前後。
4. 確認套用後，檢查備份路徑及靜態驗證結果。此處修改由你提供，未接 AI 自動生成。
5. 如要復原，按「確認還原這次修改」。若檔案又有變動會拒絕覆蓋，需人工比較。
6. 「僅靜態驗證」檢查磁碟上的版本，不是尚未套用的候選內容。
